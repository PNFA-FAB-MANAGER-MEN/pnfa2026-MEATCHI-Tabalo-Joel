### Qu'est ce que python
python est un language qui a un syntaxe proche de l'anglais donc facile à comprendre il est polivalant et gratuit.
>**Définition des quelques conceptes**
- language de programmation: c'est un moyen par lequel on donne des instructions à l'ordinateur.
- La syntaxe : est l'ensemble de règle de grammaire d'un language de programmation
- Un algorithme est un ensemble fini, logique et ordonnée d'instruction pour résoudre un problème.
- Un pseudocode : est du "faux code"
